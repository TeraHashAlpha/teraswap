## Symptom

`GET /api/quote` returns **502 Bad Gateway** (HTML), so the frontend throws
`Unexpected token '<', "<!DOCTYPE"... is not valid JSON` and shows "Quote unavailable".

## Evidence (Vercel runtime log)

- Request `GET /api/quote?...&chainId=8453` → **502**, **Function duration 22ms**, memory 311MB/2048,
  runtime nodejs24.x, region iad1.
- **External APIs: only `concise-hookworm-83451.upstash.io/pipeline ×2 → 200`.** No aggregator/RPC
  calls were made.
- Reproduces on **both Base (8453) and Ethereum (1)** — NOT chain-specific.

## Analysis

The function crashes **~22ms in, right after the Upstash calls (quote-cache read + rate-limiter)
and before any adapter HTTP/RPC call**. A 502 (not a JSON 500) means the throw escaped the route's
try/catch — consistent with an exception during the synchronous start of `fetchMetaQuote`
(building the source list) or a **module-init / circular-import / undefined-reference** error
introduced by the Sprint 9C/9D merge.

NOT the cause: Alchemy allowlist / Base RPC (failure is global + happens before any RPC call).

Likely introduced by one of:
- `api.ts` positional-array → `sourceNames` refactor (P228) — an undefined/ordering reference.
- `adapters/index.ts` `bebop` registration or a new import creating an **import cycle**
  (`constants` ↔ `chains/*` ↔ `adapters/*`; CLAUDE.md already warns constants must stay acyclic).
- the new `chains/uniswap-v3.ts` registry import path.

Why CI missed it: 1307 unit tests passed but none invoke the **built** route handler; Vitest's
module resolution tolerates a cycle that the Next.js production (nodejs) bundle does not.

## Immediate mitigation

**Rollback** to the pre-`40ddde2` production deployment (Vercel → Deployments → Promote/Instant
Rollback). No contracts changed → safe, config-free. Restores quotes on all chains.

## ⚠️ Open caveat (carry into verification)

The fix removes the **escape class** (no more 502/HTML — any throw is now JSON 500), but the
**exact prologue throw that fired in prod was NOT reproduced** (needs prod Upstash creds). The 2
Upstash calls in the failing request were `isSystemHalted` + `checkRateLimit`; the throw was just
after, before the try. Therefore: converting 502→JSON-500 prevents the crash but does **not**
guarantee quotes return. If the prologue still throws on a normal request, users now get a clean
JSON-500 instead of a quote — still broken, just not HTML.

**Implication:** Preview verification must confirm **JSON 200 with ≥1 real quote on BOTH chain 1
and 8453**, not merely "no 502". If Preview returns JSON-500 or empty quotes, the underlying
prologue throw is still live — capture its stack from the Preview function logs and reopen.
