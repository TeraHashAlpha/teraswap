# INC-2026-09-03-001 — openocean and bebop counted as active sources with no path to quoting

**Status:** resolved (both sources moved to `DISABLED_SOURCES`, `chore/disable-keyless-sources`)
**Severity:** Low — no funds impact. Both adapters run through the same quote fan-out and error
handling as every other source; a failing/skipped source never blocks or corrupts a quote from
the sources that do work. Impact is inflated source counts and one wasted fan-out slot per quote.
**Surface:** `src/lib/adapters/openocean.ts`, `src/lib/adapters/bebop.ts`, both counted in
`ADAPTER_REGISTRY` (`src/lib/adapters/index.ts`) and therefore in the public
"N integrated DEX sources" claim (`src/config/product-claims.ts`).

This file is append-only. Do not overwrite; add a dated section for any later finding.

---

## 1. What was measured

Production, 2026-09-03 10:01–10:06 UTC:

- **openocean** — every probe returned `HttpError 403`: an HTML Cloudflare challenge page served
  on what should be a JSON quote endpoint. The vendor publishes no key programme, and the owner's
  request for one went unanswered.
- **bebop** — every tick logged `[bebop] skipped on every chain — BEBOP_API_KEY not set`. The
  owner never received a key from the vendor. Bebop's demo mode carries no executable settlement,
  so this source has never produced a fillable quote in production.

**Since when:** unknown. First measured 2026-09-02 during the broader adapter-health pass this
week (`fix/dead-sources-are-loud`); confirmed again in the 2026-09-03 window above. Neither
failure mode is new — both are structural (no vendor key, no vendor access), not a transient
outage.

## 2. Impact

Both sources counted as "active" in `ADAPTER_REGISTRY`, which:

- inflated the public "N integrated DEX sources" claim (`src/config/product-claims.ts`) by 2 —
  the count included two sources that have never returned a usable quote;
- burned a fan-out slot per quote request on two adapters guaranteed to fail or skip, adding
  latency/noise to every quote for zero chance of a better price.

No funds at risk: neither adapter ever reached a state where a user could sign or settle a trade
through it.

## 3. Context this week

- `#459`, `#464`, `#465`, `#466` — the same week's adapter-health/probe work (curve pool types,
  dead-sources-are-loud circuit-breaker/quorum fixes, related env-validation hardening) that
  surfaced this pair as the two sources with no path forward, as distinct from Curve, which *is*
  quoting and has its own fix in `#466` — **Curve is NOT disabled by this incident.**

## 4. Decision

Owner decision, 2026-09-03: disable both sources via `DISABLED_SOURCES` in `src/lib/constants.ts`
(same shape as the existing `balancer`/`odos` entries — one-line reason plus a written re-enable
criterion), consistent with repo rule #8 in `CLAUDE.md` (never re-enable a disabled source without
its stated criteria being met) and rule #4 (never delete an adapter — `openocean.ts`/`bebop.ts`
stay in the tree, dormant).

Downstream effects, all derived automatically from `DISABLED_SOURCES` (no parallel lists):

- `QUOTING_ADAPTERS` / `INTEGRATED_DEX_SOURCE_COUNT` (`src/config/product-claims.ts`): 10 → 8.
- `TOGGLEABLE_SOURCES` (`src/components/SourceToggle.tsx`): now derived as
  `ADAPTER_REGISTRY` minus `DISABLED_SOURCES` keys directly, retiring the hand-kept
  `EXCLUDED_FROM_TOGGLE` set. This also drops `balancer` from the toggle for the first time —
  correct (it was already unable to quote), not a regression.
- `src/lib/env-validation.ts`: unaffected. `BEBOP_API_KEY` was never a required rule, and openocean
  has no key variable at all — neither becomes required now that the sources are disabled.

## 5. Re-enable criteria

- **openocean**: a vendor-issued key (or a documented public endpoint) returns 200 JSON for the
  canonical USDC→USDT probe on chains 1 (Ethereum) and 8453 (Base).
- **bebop**: `BEBOP_API_KEY` issued by the vendor, set in production, and a firm JAM quote returns
  an executable settlement on chains 1 and 8453.

Until then, both adapters remain in the tree (never deleted) but excluded from quoting, the public
source count, and the user-facing toggle.
